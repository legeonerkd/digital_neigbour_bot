# Digital Neighbour Bot (Telegram)

MVP-бот соседской помощи на Python + aiogram.

## Функции
- Ответы на частые вопросы (FAQ)
- Полезные контакты
- Быстрая вкладка экстренной помощи
- Каталог сервисов по категориям (с добавлением новых категорий)
- Ежедневные и одноразовые напоминания
- Просмотр ближайших напоминаний
- Отдельная подборка ближайших сервисов
- Персональный часовой пояс пользователя

## Установка
1. Создайте виртуальное окружение:
   - `python -m venv .venv`
   - `.venv\Scripts\activate`
2. Установите зависимости:
   - `pip install -r requirements.txt`
3. Создайте `.env` на основе `.env.example`
4. Запустите:
   - `python bot.py`

## Команды
- `/start` - главное меню
- `/help` - помощь
- `/contacts` - полезные контакты
- `/emergency` - экстренные номера
- `/services` - список категорий сервисов
- `/service_category <название>` - показать сервисы в категории
- `/add_category <название>` - добавить новую категорию
- `/add_service категория | название | контакт | примечание` - добавить сервис
- `/faq` - частые вопросы
- `/set_timezone +/-HH:MM` - установить ваш часовой пояс
- `/my_timezone` - показать ваш часовой пояс
- `/remind HH:MM текст` - добавить ежедневное напоминание
- `/remind_once YYYY-MM-DD HH:MM текст` - добавить одноразовое напоминание
- `/edit_reminder N HH:MM текст` - изменить ежедневное напоминание
- `/edit_once_reminder N YYYY-MM-DD HH:MM текст` - изменить одноразовое напоминание
- `/my_reminders` - показать ваши напоминания (с inline-кнопками включения/выключения и удаления)
- `/next_reminders` - показать ближайшие напоминания
- `/nearby_services` - показать подборку ближайших сервисов
- `/disable_reminder N` - временно выключить напоминание
- `/enable_reminder N` - снова включить напоминание
- `/delete_reminder N` - удалить напоминание по номеру из списка
- `/export_reminders` - экспорт напоминаний в JSON
- `/import_reminders` - импорт напоминаний (ответом на JSON или файл .json)
- `/clear_reminders` - удалить ваши напоминания

Примеры:
`/add_category Интернет-провайдер`
`/add_service Электрик | Alex Electric | +357 99 123456 | аварийный выезд`
`/service_category Электрик`

## Хранение данных
- Напоминания и сервисы сохраняются в SQLite-файл `reminders.db` рядом с `bot.py`.
- Одноразовые напоминания после отправки помечаются как выполненные и не показываются в списке.
- Часовой пояс хранится отдельно для каждого пользователя.
- Для категории `Дежурная аптека` бот показывает live-список с сайта on-duty аптек Лимассола.

## Резервная копия
- Выполните `/export_reminders` и бот отправит файл `.json`.
- Для восстановления ответьте командой `/import_reminders` на этот файл.
- Текстовый JSON в ответе тоже поддерживается как резервный вариант.

## Деплой на Railway

Проект готов к деплою на Railway. Подробная инструкция: [`RAILWAY_DEPLOY.md`](RAILWAY_DEPLOY.md)

### Быстрый старт:
1. Создайте аккаунт на [Railway](https://railway.app)
2. Подключите GitHub репозиторий
3. Добавьте переменную окружения `BOT_TOKEN`
4. Railway автоматически задеплоит бота

### Файлы конфигурации:
- [`Procfile`](Procfile) - команда запуска
- [`runtime.txt`](runtime.txt) - версия Python
- [`railway.json`](railway.json) - настройки Railway
- [`.railwayignore`](.railwayignore) - исключаемые файлы
