# Инструкция по тестированию Digital Neighbour Bot

## Подготовка к тестированию

### 1. Проверка переменных окружения

Убедитесь, что файл `.env` существует и содержит токен бота:

```bash
# Проверить наличие файла
ls .env

# Если файла нет, создайте его на основе .env.example
copy .env.example .env
```

Откройте `.env` и добавьте ваш токен:
```
BOT_TOKEN=ваш_реальный_токен_бота
```

### 2. Установка зависимостей

```bash
# Создать виртуальное окружение (если еще не создано)
python -m venv .venv

# Активировать
.venv\Scripts\activate  # Windows
# или
source .venv/bin/activate  # Linux/Mac

# Установить зависимости
pip install -r requirements.txt
```

### 3. Проверка синтаксиса

```bash
# Проверить bot.py
python -m py_compile bot.py

# Проверить все handlers
python -m py_compile handlers/reminders.py
python -m py_compile handlers/services.py
python -m py_compile handlers/callbacks.py
python -m py_compile handlers/backup.py
```

## Запуск бота

```bash
python bot.py
```

Вы должны увидеть:
```
INFO:root:Бот запущен
```

## Тестирование функций

### Базовые команды

1. **Запуск бота**
   - Отправьте `/start` в Telegram
   - Должно появиться главное меню с кнопками

2. **Справка**
   - Отправьте `/help`
   - Должен появиться список всех команд

3. **FAQ**
   - Нажмите кнопку "❓ FAQ" или отправьте `/faq`
   - Должен появиться список вопросов и ответов

4. **Контакты**
   - Нажмите кнопку "📞 Полезные контакты" или отправьте `/contacts`
   - Должен появиться список контактов

5. **Экстренная помощь**
   - Нажмите кнопку "🆘 Экстренная помощь" или отправьте `/emergency`
   - Должны появиться экстренные номера

### Часовой пояс

1. **Установка часового пояса**
   ```
   /set_timezone +02:00
   ```
   Ответ: "Часовой пояс сохранен: UTC+02:00"

2. **Проверка часового пояса**
   ```
   /my_timezone
   ```
   Ответ: "Ваш часовой пояс: UTC+02:00"

### Напоминания

1. **Создание ежедневного напоминания**
   ```
   /remind 19:30 Вынести мусор
   ```
   Ответ: "Добавил ежедневное напоминание на 19:30..."

2. **Создание одноразового напоминания**
   ```
   /remind_once 2026-02-25 14:00 Встреча с врачом
   ```
   Ответ: "Добавил одноразовое напоминание..."

3. **Просмотр напоминаний**
   - Нажмите кнопку "⏰ Мои напоминания" или отправьте `/my_reminders`
   - Должен появиться список напоминаний с кнопками управления

4. **Ближайшие напоминания**
   - Нажмите кнопку "⏰ Ближайшие напоминания" или отправьте `/next_reminders`
   - Должен появиться список ближайших 5 напоминаний

5. **Управление напоминаниями**
   - В списке напоминаний нажмите кнопку "Выключить 1"
   - Напоминание должно выключиться
   - Нажмите "Включить 1" - должно включиться
   - Нажмите "Удалить 1" - должно удалиться

6. **Редактирование напоминания**
   ```
   /edit_reminder 1 20:00 Новый текст
   ```

7. **Удаление всех напоминаний**
   ```
   /clear_reminders
   ```

### Сервисы

1. **Просмотр категорий**
   - Нажмите кнопку "🛠 Сервисы" или отправьте `/services`
   - Должен появиться список категорий с кнопками

2. **Просмотр сервисов в категории**
   ```
   /service_category Электрик
   ```
   Или нажмите кнопку категории

3. **Добавление категории**
   ```
   /add_category Интернет-провайдер
   ```

4. **Добавление сервиса**
   ```
   /add_service Электрик | Alex Electric | +357 99 123456 | аварийный выезд
   ```

5. **Ближайшие сервисы (с геолокацией)**
   - Нажмите кнопку "📍 Ближайшие сервисы" или отправьте `/nearby_services`
   - Должна появиться кнопка "📍 Отправить геолокацию"
   - Нажмите кнопку и отправьте геолокацию
   - Должен появиться список ближайших сервисов

### Резервное копирование

1. **Экспорт напоминаний**
   ```
   /export_reminders
   ```
   Должен прийти JSON файл с напоминаниями

2. **Импорт напоминаний**
   - Отправьте `/import_reminders` как ответ на JSON файл
   - Или отправьте `/import_reminders` и вставьте JSON текстом

### Callback-кнопки

1. **Переключение напоминания**
   - В `/my_reminders` нажмите "Выключить 1"
   - Должно появиться сообщение "Напоминание выключено"

2. **Удаление напоминания**
   - В `/my_reminders` нажмите "Удалить 1"
   - Должно появиться сообщение "Напоминание удалено"

3. **Выбор категории сервиса**
   - В `/services` нажмите кнопку категории
   - Должен появиться список сервисов

## Проверка воркера напоминаний

1. Создайте напоминание на ближайшее время (через 1-2 минуты)
2. Дождитесь времени срабатывания
3. Должно прийти сообщение "⏰ Напоминание: ..."

## Troubleshooting

### Бот не запускается

**Ошибка: "BOT_TOKEN не найден"**
- Проверьте наличие файла `.env`
- Убедитесь, что в нем есть строка `BOT_TOKEN=...`

**Ошибка импорта модулей**
```bash
# Переустановите зависимости
pip install -r requirements.txt --force-reinstall
```

**Ошибка БД**
```bash
# Удалите старую БД и создайте новую
del reminders.db  # Windows
# или
rm reminders.db  # Linux/Mac

# Запустите бота снова
python bot.py
```

### Кнопки не работают

1. **Проверьте логи**
   - В терминале должны быть сообщения об ошибках
   - Если есть ошибки импорта - проверьте все файлы handlers

2. **Проверьте регистрацию обработчиков**
   - Откройте [`bot.py`](bot.py)
   - Убедитесь, что все обработчики зарегистрированы в `register_handlers()`

3. **Перезапустите бота**
   - Остановите бота (Ctrl+C)
   - Запустите снова `python bot.py`

### Сервисы не отвечают

1. **Проверьте наличие категорий**
   ```
   /services
   ```
   Должны быть категории по умолчанию: Дежурная аптека, Электрик, Сантехник, Автосервис

2. **Добавьте тестовый сервис**
   ```
   /add_service Электрик | Тест | +123456 | тест
   ```

3. **Проверьте категорию**
   ```
   /service_category Электрик
   ```

4. **Проверьте логи**
   - Должны быть сообщения об ошибках в терминале

### Геолокация не работает

1. **Убедитесь, что Telegram разрешил доступ к геолокации**
2. **Попробуйте отправить геолокацию вручную** (без кнопки)
3. **Проверьте логи** на наличие ошибок

## Логи

Бот выводит логи в консоль:
- `INFO` - информационные сообщения
- `WARNING` - предупреждения
- `ERROR` - ошибки
- `EXCEPTION` - исключения с трейсбеком

Для более детального логирования измените уровень в [`bot.py`](bot.py):
```python
logging.basicConfig(level=logging.DEBUG)
```
